# P12. 文档命令化生成（gen-docs 命令）

- 状态：`[ ]`（排队中：task-p11 执行期间按 R27 排队）
- 目标：实现 `gen-docs` 命令，把双轨文档的机械部分命令化，降低每次 API 变更时的文档维护消耗

## 前置依赖
- task-p11（packages 拆分）完成后再开工（避免同文件冲突）

## 步骤
1. **dart doc HTML 产出**：命令遍历 packages/* 与根包执行 `dart doc`，产物输出各包 `doc/api/`（gitignore）
2. **公开 API 清单提取**：脚本扫描各包 barrel export 的公开类/方法/字段 + /// 首句摘要，生成 Markdown API 索引（`docs/api-index.md`），与源码保持机械同步
3. **双轨一致性校验**：比对 `docs/components|docs/*.md` 人工文档中覆盖的 API 与实际导出 API，列出缺失/多余清单（仅提示，不自动改写人工内容）
4. **命令沉淀**：按脚本三件套规范（.bat 纯 ASCII 启动器 + .ps1 + .sh）放 `scripts/gen_docs.*`；命令权威定义写入 ai-brain commands 技能（含参数/边界/注意事项）
5. 验证：对四个 packages 跑通生成与校验；故意改一个 API 不更新文档时校验能报出缺失

## 验收标准
- [ ] 一条命令完成 dart doc 产出 + API 索引生成 + 一致性校验
- [ ] 命令已沉淀 commands 技能并内联说明
- [ ] API 变更时跑一条命令即可同步机械文档内容
