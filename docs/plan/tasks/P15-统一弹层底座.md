# P15. 统一弹层底座 popup_engine（R30 轮子吸收）

- 状态：`[ ]`（排队：task-p08-tooltipfix 修复完成后开工）
- 目标：吸收 pub.dev/packages/popover（minikin/popover 0.5.1，MIT）的方向决策/边界翻转/滑动夹回算法，建 `antd_flutter_ui/src/engines/popup_engine.dart` 统一弹层底座，供 AntTooltip / AntPopover / AntPopconfirm / AntDropdown 四大弹层复用

## 已完成调研结论（task-p08-tooltipfix，commit 16b6546）
- popover 核心实现：PopoverRenderShiftedBox（RenderShiftedBox 子类）——首选方向放不下翻到对侧、macOS 再试垂直两侧、取空间更大侧并缩小 body；沿边居中后滑动夹回屏内（遵守 safe area/键盘边距）；箭头 tip clamp；PopoverPath/ApplePopoverPath 箭头+气泡合成单一路径
- **吸收**：方向决策 + 边界翻转 + 滑动夹回算法（注明来源 minikin/popover，MIT，保留版权声明）+ 可选箭头合成 Path
- **不吸收**：route/Navigator 弹出方式（hover tooltip 需轻量 Overlay）、iOS Liquid Glass/spring 原生视觉

## 步骤
1. `ui/src/engines/popup_placement_engine.dart`：吸收算法（纯计算层，可单测）
2. `ui/src/engines/popup_engine.dart`：Overlay 基座 widget（placement 计算 + 箭头渲染 + hover/click/focus 触发器统一）
3. 四弹层组件逐个迁移到底座（每迁移一个跑该组件全部测试 + example 视觉抽查）
4. 当前 AntTooltip「固定锚点偏移不防溢出屏幕」的缺陷随底座修复（边界自动翻转）

- [ ] 边界翻转：tooltip/popover 贴近屏幕边缘时自动翻向，不溢出视口
- [ ] 既有测试全过 + 新增边界翻转测试
