# AntMaterialTheme

> 种类：扩展

```dart
extension AntMaterialTheme on AntThemeData
```

antd 主题 → Flutter Material 主题转换扩展。

## 方法

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| `_buildColorScheme` | `ColorScheme` | — |
| `_buildTextTheme` | `TextTheme` | — |
| `_buildThemeData` | `ThemeData` | — |
| `_inputBorder` | `OutlineInputBorder` | — |
| `_resolveByDisabled` | `WidgetStateProperty<Color?>` | 按控件禁用态解析颜色：未禁用取 enabled，禁用取 disabled |
| `toThemeData` | `ThemeData` | 转换为 Flutter ThemeData |
