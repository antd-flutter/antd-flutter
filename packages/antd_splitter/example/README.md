# antd_splitter_example

Ant Design v6 Splitter for Flutter 组件演示画廊（开发者本地运行 demo 用）。

```bash
cd packages/antd_splitter/example
flutter pub get
flutter run
```

覆盖形态：基本用法 / 垂直布局 / 双向嵌套 / 拖拽限制（min·max·resizable）/ 折叠面板 / 受控模式 / 懒拖拽与回调 / 双击重置。

> 分割线样式（粗细/颜色/hover）为组件内置令牌（splitBarSize = 2 / splitBarDraggableSize = 20），无对外样式参数。
