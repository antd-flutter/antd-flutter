# AntPullToRefreshPointer

> 种类：枚举

```dart
enum AntPullToRefreshPointer
```

下拉刷新指针位置。

对齐 antd-mobile PullToRefresh 的 pointer 属性：
- top：从列表顶部下拉刷新（默认）
- bottom：从列表底部上拉刷新

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `top` | 顶部下拉（默认） |
| `bottom` | 底部上拉 |
