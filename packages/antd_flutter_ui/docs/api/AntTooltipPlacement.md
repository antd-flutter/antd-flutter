# AntTooltipPlacement

> 种类：枚举

```dart
enum AntTooltipPlacement
```

气泡弹出位置。

对齐 antd React Tooltip 的 `placement`：
top / bottom / left / right 及 8 个角落变体。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `top` | 上方弹出（默认） |
| `topLeft` | 上方弹出，左对齐 |
| `topRight` | 上方弹出，右对齐 |
| `bottom` | 下方弹出 |
| `bottomLeft` | 下方弹出，左对齐 |
| `bottomRight` | 下方弹出，右对齐 |
| `left` | 左侧弹出 |
| `leftTop` | 左侧弹出，顶部对齐 |
| `leftBottom` | 左侧弹出，底部对齐 |
| `right` | 右侧弹出 |
| `rightTop` | 右侧弹出，顶部对齐 |
| `rightBottom` | 右侧弹出，底部对齐 |
