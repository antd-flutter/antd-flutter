# AntFlexJustify

> 种类：枚举

enum AntFlexJustify

主轴对齐方式。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `start` | 起点对齐（默认） |
| `end` | 终点对齐 |
| `center` | 居中对齐 |
| `spaceBetween` | 两端对齐，元素间间隔相等 |
| `spaceAround` | 每个元素两侧间隔相等 |
| `spaceEvenly` | 所有间隔完全相等 |
