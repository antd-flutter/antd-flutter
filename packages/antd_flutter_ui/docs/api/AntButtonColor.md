# AntButtonColor

> 种类：枚举

```dart
enum AntButtonColor
```

按钮颜色语义（antd v6 `color` 属性）。

`default` 使用中性色；`primary`/`danger` 使用主题色令牌；
`link` 使用链接色令牌（colorLink 体系，仅 type=link 使用）；
预设色（blue/purple/…）使用 `AntButtonPresetColors` 生成的色板。
