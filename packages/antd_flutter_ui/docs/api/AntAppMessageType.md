# AntAppMessageType

> 种类：枚举

```dart
enum AntAppMessageType
```

经 AntApp 弹出 message 的类型。

与 AntMessage 的类型一一对应，作为 API 层的稳定入口枚举。

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `info` | 信息提示 |
| `success` | 成功 |
| `warning` | 警告 |
| `error` | 错误 |
| `loading` | 加载中 |
