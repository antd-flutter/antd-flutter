# AntPopconfirmPlacement

> 种类：枚举

```dart
enum AntPopconfirmPlacement
```

气泡确认框弹出位置（同 antd v6 Popconfirm placement，参考 Popover 九/十二方向）。

- 上：`topLeft` / `topCenter` / `topRight`
- 下：`bottomLeft` / `bottomCenter` / `bottomRight`
- 左：`leftTop` / `leftCenter` / `leftBottom`
- 右：`rightTop` / `rightCenter` / `rightBottom`

## 枚举值

| 名称 | 说明 |
| --- | --- |
| `topLeft` | 上方，左对齐 |
| `topCenter` | 上方，水平居中 |
| `topRight` | 上方，右对齐 |
| `bottomLeft` | 下方，左对齐（默认） |
| `bottomCenter` | 下方，水平居中 |
| `bottomRight` | 下方，右对齐 |
| `leftTop` | 左侧，顶部对齐 |
| `leftCenter` | 左侧，垂直居中 |
| `leftBottom` | 左侧，底部对齐 |
| `rightTop` | 右侧，顶部对齐 |
| `rightCenter` | 右侧，垂直居中 |
| `rightBottom` | 右侧，底部对齐 |
